#+title: Credentials

We define the auth credentials as restclient variables to use them in
our requests in examples.org:
Replace the Authorization token with the one you created.

#+name: headervars-grafana-a
#+begin_src restclient
:headers = <<
Accept: application/json
Authorization: Bearer <token>
#
#+end_src

#+name: grafana-a
#+begin_src org :noweb yes
<<headervars-grafana-a>>
#+end_src
